# 密码重置与账号安全管理

## 概述

公司统一使用域账号（AD账号）作为员工身份认证凭证，支持访问各类系统和应用。本文档介绍密码重置、账号解锁和安全管理的相关流程。

## 域账号说明

### 什么是域账号
- 由IT部门统一分配的企业账号
- 格式：工号（如 S12345）
- 密码：与邮箱、VPN、内网系统等通用
- 一次登录，访问所有授权资源

### 账号安全策略
- 密码长度：至少8位
- 密码复杂度：必须包含大写字母、小写字母、数字
- 密码有效期：90天
- 密码历史：不能重复使用最近5次的密码
- 登录失败锁定：连续输错5次锁定30分钟

## 密码重置方法

### 方法一：自助网页重置（推荐）

**适用场景：** 忘记密码、密码过期、需要修改密码

**操作步骤：**
1. 访问密码管理平台：https://password.company.com
2. 点击"忘记密码"或"重置密码"
3. 输入工号和注册时的手机号
4. 接收短信验证码
5. 回答安全问题（首次使用需设置）
6. 设置新密码
7. 确认后完成

**注意事项：**
- 必须使用公司注册的手机号
- 验证码有效期15分钟
- 新密码不能与最近5次密码相同
- 密码修改后约5分钟内全系统生效

### 方法二：Windows系统内修改

**适用场景：** 知道当前密码，想更换新密码

**操作步骤：**
1. 按 `Ctrl + Alt + Delete`
2. 选择"更改密码"
3. 输入旧密码
4. 输入新密码（两次确认）
5. 回车确认

**提示：** 建议在密码到期前主动修改，避免影响使用。

### 方法三：联系IT服务台

**适用场景：** 自助重置失败、手机号已变更、账号异常

**需要提供的信息：**
- 工号
- 姓名
- 部门
- 身份证号后6位（身份核验）
- 常用联系电话

**联系方式：**
- 热线：400-XXX-XXXX（工作时间）
- 紧急：拨打分机 9999（7x24小时）

## 账号解锁

### 为什么会被锁定
- 连续输错密码5次
- 恶意登录尝试
- 多设备同时登录失败叠加

### 自动解锁
- 锁定时间：30分钟
- 30分钟后系统自动解锁
- 锁定期间再次尝试会重置锁定计时

### 手动解锁（紧急情况）
如果等不及自动解锁，可以通过以下方式：
1. 拨打IT服务台热线
2. 提供身份核验信息
3. 说明情况并申请紧急解锁
4. IT确认后立即解锁

## 首次登录与初始化

### 新员工账号激活
1. 入职当天HR会通知IT创建账号
2. 初始密码通过短信发送到个人手机
3. 首次登录必须修改初始密码
4. 设置安全问题和备用联系方式
5. 完成MFA（多因素认证）绑定

### MFA 多因素认证

**什么是MFA：**
除了密码之外，还需要第二种验证方式，大大提升账号安全性。

**支持的验证方式：**
1. 手机短信验证码
2. 身份验证器App（推荐，如Microsoft Authenticator）
3. 硬件令牌（特殊岗位）

**绑定步骤：**
1. 访问 https://aka.ms/mfasetup
2. 使用公司账号登录
3. 选择验证方式
4. 按提示完成绑定
5. 保存恢复代码（非常重要！）

## 密码安全最佳实践

### 1. 设置强密码
✅ 好的密码示例：
- `Summer2024!Office` （短语+数字+符号）
- `W0rk!Sm@rt2024` （替换字母为数字/符号）

❌ 避免的密码：
- `123456`、`password` 等常见密码
- 生日、手机号、姓名拼音
- 连续字母或数字（abcd、1234）
- 公司名+简单数字

### 2. 密码管理建议
- 每个系统使用不同密码
- 使用密码管理器（如1Password、LastPass）
- 定期更换重要账号密码
- 不要在便签、文档中记录密码
- 不要通过IM、邮件发送密码

### 3. 警惕钓鱼攻击
- 不要点击可疑邮件中的链接
- 不要在非官方网站输入公司密码
- IT部门绝不会通过邮件索要你的密码
- 收到可疑邮件立即转发给安全组

### 4. 设备安全
- 设置电脑开机密码
- 离开座位时锁定屏幕（Win+L）
- 不要让他人使用你的账号
- 公共电脑使用后务必退出登录

## 常见问题

### Q: 密码改了之后，VPN连不上了？
A: 因为VPN客户端缓存了旧密码。打开VPN设置，删除保存的密码，重新输入新密码即可。

### Q: Outlook一直弹输入密码的框？
A: 
1. 打开凭据管理器（Control Panel → Credential Manager）
2. 删除所有包含公司域名的凭据
3. 重启Outlook，重新输入新密码

### Q: 手机收不到验证码怎么办？
A:
1. 检查手机信号是否正常
2. 查看是否被短信拦截软件屏蔽
3. 等待60秒后重新获取
4. 仍不行联系IT更新手机号

### Q: 离职后账号会保留多久？
A: 
- 离职当天：账号禁用
- 30天后：邮箱自动转发给直属上级
- 90天后：账号彻底删除
- 如需保留数据请提前申请数据导出
