# VPN 故障排查指南

## 概述

VPN（虚拟专用网络）是员工远程办公时访问公司内部资源的主要方式。本指南涵盖了常见的VPN连接问题及解决方案。

## 常见问题及解决方案

### 1. 认证失败（Authentication Failed）

**现象：** 输入账号密码后提示认证失败。

**排查步骤：**
- 确认账号密码是否正确（注意大小写）
- 确认账号是否被锁定（连续输错5次会锁定30分钟）
- 确认密码是否已过期（域账号密码每90天需更换）
- 尝试登录公司内网其他系统验证账号有效性

**解决方法：**
- 密码过期：通过 https://password.company.com 自助重置
- 账号锁定：等待30分钟自动解锁，或联系IT服务台手动解锁
- 忘记密码：使用自助密码重置功能

### 2. 连接超时（Connection Timeout）

**现象：** VPN客户端一直显示"正在连接"，最终超时失败。

**排查步骤：**
- 检查本地网络是否正常（尝试访问其他网站）
- 确认VPN服务器地址是否正确：vpn.company.com
- 检查防火墙是否阻止了VPN连接
- 尝试切换网络（如手机热点）验证是否为网络环境问题
- 确认是否在国内（部分运营商可能阻断VPN协议）

**解决方法：**
- 家庭网络：重启路由器后重试
- 酒店/公共网络：可能需要先完成网页认证
- 国内网络：使用公司提供的备用接入点

### 3. 连接成功但无法访问内部资源

**现象：** VPN显示已连接，但无法打开内网网站、无法访问文件服务器。

**排查步骤：**
- 确认VPN状态显示"已连接"
- 尝试ping内部服务器IP（如 10.0.0.1）
- 检查DNS设置是否正确获取
- 运行 `ipconfig /all` 查看是否获取到公司DNS

**常见原因：**
- 本地路由冲突（家用路由器网段与公司网段重叠）
- DNS解析失败
- 本地安全软件拦截

**解决方法：**
1. 断开VPN重新连接
2. 以管理员身份运行CMD，执行：
   ```
   ipconfig /flushdns
   ipconfig /registerdns
   ```
3. 修改家用路由器LAN口网段，避免使用 10.0.0.0/8 或 192.168.1.0/24

### 4. 速度很慢或频繁掉线

**现象：** VPN连接正常但网速极慢，或频繁断开重连。

**可能原因：**
- 本地网络质量差（丢包率高、延迟大）
- WiFi信号不稳定
- VPN服务器负载过高

**优化建议：**
- 使用有线网络代替WiFi
- 关闭其他占用带宽的应用
- 避开高峰期（上午9-10点、下午2-3点）
- 选择就近的VPN接入点

## VPN客户端安装

### Windows系统
1. 从IT软件门户下载公司VPN客户端
2. 以管理员身份运行安装程序
3. 安装完成后导入配置文件（联系IT获取）
4. 首次连接时安装安全证书

### macOS系统
1. 从App Store或公司软件门户下载
2. 安装后在系统偏好设置中允许VPN配置
3. 添加配置文件
4. 首次连接时在钥匙串中信任证书

## 安全注意事项

1. **绝不共享账号**：VPN账号仅限本人使用
2. **公共WiFi谨慎使用**：使用VPN前确认网络安全性
3. **及时断开**：不需要访问内网资源时断开VPN
4. **定期更新客户端**：保持客户端为最新版本
