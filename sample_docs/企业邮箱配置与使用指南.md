# 企业邮箱配置与使用指南

## 概述

公司使用Exchange企业邮箱系统，支持PC客户端、手机端和网页版访问。本文档介绍邮箱的配置方法和常见问题处理。

## 邮箱登录方式

### 网页版（Outlook Web App）
- 地址：https://mail.company.com
- 账号：工号@company.com
- 密码：域账号密码
- 支持浏览器：Chrome、Edge、Firefox、Safari

### Outlook客户端
- Windows：随Office套件一起安装
- macOS：从App Store下载Outlook for Mac
- 首次配置需要域账号和服务器地址

### 手机端
- iPhone：系统自带邮件App / Outlook App
- Android：Outlook App / 自带邮件应用
- 推荐使用官方Outlook App，功能最完整

## Outlook客户端配置

### Windows 版 Outlook

**自动配置（推荐）：**
1. 打开 Outlook
2. 文件 → 添加账户
3. 输入完整邮箱地址
4. 输入域账号密码
5. 等待自动配置完成

**手动配置：**
1. 选择"手动设置或其他服务器类型"
2. 选择"Microsoft Exchange Server 或 兼容的服务"
3. 服务器：mail.company.com
4. 用户名：工号
5. 点击"其他设置" → 安全 → 加密设置选择"自动"

### macOS 版 Outlook

1. 打开 Outlook
2. Outlook → 设置 → 账户
3. 点击"+" → 新建账户
4. 输入邮箱地址 → 继续
5. 选择"Exchange" → 输入密码
6. 等待配置完成

## 手机端配置

### iPhone（iOS）

**方法一：系统邮件App**
1. 设置 → 邮件 → 账户 → 添加账户
2. 选择"Exchange"
3. 输入邮箱地址和描述
4. 选择"配置"或"手动"
5. 服务器：mail.company.com
6. 域：company
7. 用户名：工号
8. 密码：域账号密码

**方法二：Outlook App**
1. 从App Store下载"Microsoft Outlook"
2. 打开应用 → 添加账户
3. 输入邮箱地址
4. 选择"Exchange"
5. 输入密码登录

### Android

1. 从应用商店下载"Microsoft Outlook"
2. 打开应用 → 开始使用
3. 输入邮箱地址 → 继续
4. 选择"Exchange"
5. 输入密码和服务器信息
6. 可能需要设置设备安全策略

## 常见问题

### 1. 无法收发邮件

**排查步骤：**
- 检查网络连接是否正常
- 确认账号密码是否正确
- 测试网页版是否能登录
- 检查Outlook是否显示"已连接"

**常见原因：**
- 密码已过期未更新
- 邮箱空间已满
- 客户端配置错误
- 网络代理问题

### 2. 邮箱空间已满

**现象：** 无法接收新邮件，发送邮件提示空间不足。

**解决方法：**
1. 清理不需要的邮件（尤其是带大附件的）
2. 将旧邮件归档到本地PST文件
3. 删除"已删除邮件"和"垃圾邮件"文件夹
4. 清空"已发送邮件"中不需要的

**查看邮箱容量：**
- Outlook：文件 → 账户设置 → 邮箱设置 → 查看配额
- 网页版：设置 → 常规 → 存储

**申请扩容：**
- 经理审批后提交IT工单
- 标准配额：5GB
- 高级配额：20GB（需部门VP审批）

### 3. 邮件发送失败/退信

**常见退信原因：**
- 收件人地址错误
- 收件人邮箱已满
- 附件过大（公司限制单封邮件50MB）
- 被对方服务器判定为垃圾邮件
- 收件人不存在

**处理方法：**
- 仔细核对收件人邮箱地址
- 大文件使用文件共享平台，不要发邮件
- 外部邮件退信可尝试用其他邮箱联系对方
- 反复退信联系IT协助排查

### 4. 垃圾邮件过滤

**工作原理：**
公司邮件系统有多层垃圾邮件过滤，包括：
- 发件人信誉检查
- 内容关键词过滤
- 附件病毒扫描
- 外部邮件标记

**误判处理：**
1. 检查"垃圾邮件"文件夹
2. 将正常邮件标记为"非垃圾邮件"
3. 添加发件人到安全发件人列表
4. 反复误判联系IT调整过滤规则

### 5. 忘记邮箱密码

邮箱密码与域账号密码一致，重置方法：
1. 访问 https://password.company.com
2. 输入工号和注册手机号
3. 接收短信验证码
4. 设置新密码
5. 密码要求：8位以上，包含大小写字母和数字

## 邮件使用规范

### 发送规范
- 主题明确，简明扼要
- 收件人、抄送、密送使用正确
- 重要邮件设置已读回执
- 外部邮件注意保密

### 回复规范
- 及时回复重要邮件（工作时间内2小时）
- 回复时引用原文，保留上下文
- 避免"全部回复"滥用
- 跨部门沟通注意抄送相关负责人

### 安全提醒
- 警惕钓鱼邮件，不要点击可疑链接
- 不要通过邮件发送密码等敏感信息
- 外部邮件会有【外部】标识，注意甄别
- 发现可疑邮件立即报告IT安全组
